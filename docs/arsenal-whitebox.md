# 军火库白盒原型 r1

## 本次交付

军火库 →「白盒设备」或效果链的 TS808/SD-1/RAT 节点，选择设备，开启模块，调节参数后保存。
白盒单块可单独使用，也可排在 NAM/IR、EQ、Delay、Reverb 的前后。
当前一个预设内有一个可选型号的白盒单块实例；左右声道独立保存电路状态。

**这是基于电路的实验原型，不是已经校准的完整实机复刻。** 非线性核心是物理二极管网络的标量 MNA 求解；缓冲、运放、部分音调网络是降阶模型。没有引入第三方效果器实现或新增第三方 DSP 许可。

## 电路及参数边界

| 原型 | 电路核心 | 简化与尚待验证的部分 |
| --- | --- | --- |
| TS808 经典反馈削波 | 理想运放；4.7kΩ/47nF 接地支路；51kΩ + 500kΩ Drive 反馈；51pF 与反并联二极管共同求解；加载的被动 RC + 理想主动 Tone 网络 | 忽略缓冲管、有限运放增益及电源动态；9V 供电摆幅以 ±4V 近似；音调电位器为20kΩ；器件未按实机拟合 |
| SD-1 经典不对称反馈族 | 4.7kΩ/47nF；33kΩ + 1MΩ 线性 Drive；100pF；一个方向一颗、另一方向两颗二极管 | 音调使用独立的10kΩ/18nF、470Ω/27nF、10kΩ反馈和10kΩ/10nF后极点降阶配置；这一配置为开发原型，未逐元件核验某一生产修订；不能视为只修改TS对称性，也不能视为完整SD-1复刻 |
| 经典硅二极管 RAT 电路族 | 47Ω/2.2µF 和560Ω/4.7µF 双增益支路；100kΩ Drive/100pF；4.7µF 耦合、1kΩ限流与对地二极管；1.5kΩ + 100kΩ Filter/3.3nF | 采用1MHz增益带宽、0.3V/µs转换速率与±4V摆幅的降阶运放；非完整LM308器件宏模型；Filter与后级负载间进一步耦合未完全保留 |

旋钮均为0–100%，TS Drive、RAT Distortion/Filter、Level使用可审查的近似音频规律 `(10^(2x)-1)/99`，SD Drive使用线性规律。真实电位器的制造公差与规律尚待测量。Tone与Level不是用通用峰值EQ替代的设备标签。

二极管统一使用名义硅模型 Is=2.52nA、n=1.752、Vt=25.85mV；SD 的串联数量影响每个方向的指数电流。
这不是对某批次 MA150/1N914/1N4148 的实测参数。

## 数值实现

电容使用梯形伴随状态。反馈削波端口每个内部采样求解：

```
(1/Rf + 2*fs*Cf)*w + Is*(exp(w/nVt) - exp(-w/mVt)) = branchCurrent - capacitorHistory
output = input + w
```

因此反馈支路保留输入直达分量、频率相关增益和电容状态；并非普通高通串联静态 `tanh`。RAT 在运放之后求解单独的对地削波端口，并将耦合电容纳入端口等效阻抗。

非线性端口使用前一采样解初始化、有括区间保护的12次牛顿迭代；未收敛时最多32次二分，固定工作上限。音调线性节点直接消元，采样处理没有矩阵分配或求逆。处理路径使用固定数组，不读文件、不解析JSON、不发送IPC。

整个白盒电路工作于2×或4×内部采样率，两侧使用Blackman窗sinc FIR。两侧滤波合计固定32个设备采样延迟；旁通干声同样延迟32帧并参与10ms平滑交叉淡化。现有128帧DSP适配器使无NAM重采样时总算法延迟为160帧（48kHz时约3.33ms），**不是声卡往返延迟**。离线渲染通过 `Effects::latency()` 裁掉前导算法延迟。过采样不等于已证明不存在可闻混叠。

Drive/Tone/Level/输入标定与旁通均以10ms时间常数平滑。设备、版本、过采样和模块顺序进入结构键，使用现有离线准备/实例替换路径，失败保留上一实例。普通参数通过已有控制队列更新；资源未变化时不再逐次读取模型/IR。实例替换仍沿用现有淡入，尚未实现旧新实例延迟对齐的完整交叉淡化。

`inputVolts` 表示归一化数字满幅对应的电路伏数（0.1–10 V/FS），默认1只作为起点；输出用同一标定换回归一化信号。声卡已经完成采集，不能据此声称恢复了真实拾音器负载。最终软件Output与设备Level分开。

## 存储和现有链路

- 旧的四模块快照加载时规范化为五模块，在前方补入默认关闭的drive；保留原有模块顺序与设置。公共预设、轨道快照和IPC使用同一规范化规则。
- 设备ID、revision、控制值、标定和过采样写入快照，不依赖外部音色资源。
- 原生监听、轨道离线湿声渲染和导出缓存共用同一C++代码。DSP缓存版本升为 `bb-dsp-2-whitebox-1-nam-0.5.4`。
- WASM已经重编译并做数值对照；当前仓库的Web Audio录音轨回放尚未接入该WASM处理节点，本次不宣称完成录后实时回放链路。
- 原始采集缓冲区不进入可修改的效果工作缓冲区，录音仍保留干声。

## 验证及复现

准备现有原生构建目录后：

```
cmake --build native/audio-host/build/darwin-arm64 --parallel 4
# Windows 使用对应配置目录；可用 BB_EFFECTS_TEST 指定测试可执行文件。
# 先在 shell 中加载本机 Emscripten 环境：
pnpm build:effects:wasm
pnpm test:whitebox
pnpm typecheck
pnpm test
pnpm build
```

`whitebox_test.cpp` 检查二极管KCL残差、旁通逐样本一致、44.1/48/96/192kHz稳定性、快速参数变化、静音恢复、RAT Filter方向和设备族差异。TS额外对照独立连续时间小信号传递函数（50/440/2000Hz，输入0.1mV，192kHz基准，允许2%误差）；这只验证实现的简化电路。

`scripts/test-whitebox.mjs` 使用固定种子立体声输入，覆盖三种型号与2×/4×，串接立体声IR、EQ、Delay和Reverb。比较原生127/257帧、WASM113帧调用；原生分块应逐样本一致，原生/WASM相对RMS阈值1e-4，同时检查输入缓冲区哈希不变。临时文件结束后自动清理。

没有声卡30分钟压力验收、实机重放测量、SPICE全电路对照或Windows本机运行结果，不能从离线测试推断它们已通过。

- 49 个测试文件、280 项测试通过；类型检查和生产构建通过；原生宿主自测通过。
