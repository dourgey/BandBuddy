BandBuddy `1.1.0` 把单曲练习扩展成一套可以录音、比较 Take、编排整场排练并跟随歌词的本地工作台，同时为中国大陆与受限网络补齐可切换、可校验的环境安装链路。

## 新功能

- 在单曲练习室创建多条录音轨，保留和切换多个 Take，独立命名、Mute、Solo、调整增益与对齐偏移。
- 新增基于 RtAudio / PortAudio 的原生音频宿主，支持 WASAPI、CoreAudio 和系统可用时的 ASIO；提供输入设备、通道、采样率、Buffer 与电平测试设置。
- 新增排练编排单：拖放歌曲和空白衔接、连续播放整条时间线，并为整场排练进行多轨录音、暂停和续录。
- 排练录音绑定编排修订；可以从录音对应版本复制新编排，避免后续调整破坏旧 Take 的上下文。
- 支持导入 LRC 时间轴歌词，并在独立置顶桌面歌词窗口中跟随单曲或排练播放。
- 当前练习混音可以包含多条启用的录音轨，并保持录制时的速度和时间位置。

## 环境与可靠性

- 应用内新增“中国大陆镜像 / 官方源 / 自定义源”设置；大陆预设使用 npmmirror、阿里云 PyPI/PyTorch 与 ModelScope 固定模型 revision。
- 新增 `pnpm install:cn`、`pnpm dev:cn` 和 `pnpm tools:fetch:cn`，支持多个 GitHub 代理、断点续传、官方源回退与命令级镜像配置。
- HTDemucs 6s 权重升级为完整 SHA-256 校验；FFmpeg 改用固定 release，桌面工具下载采用事务式替换，失败时保留原有可用版本。
- 新增 Windows 与 macOS 原生音频宿主构建和自测；数据库迁移会保留已有曲库与练习状态。

## 下载

- `BandBuddy-1.1.0-x64.exe`：Windows 10/11 x64 安装版。
- `BandBuddy-1.1.0-x64-portable.exe`：Windows 10/11 x64 便携版。
- `BandBuddy-1.1.0-macos-x64.dmg` / `.zip`：Intel Mac。
- `BandBuddy-1.1.0-macos-arm64.dmg` / `.zip`：Apple Silicon Mac。
- `SHA256SUMS*.txt`：对应平台安装包的 SHA-256 校验值。

Windows 社区构建在没有 Authenticode 证书时会显示“未知发布者”；macOS 构建目前未使用 Developer ID 签名或公证。首次录音前请在设置中选择设备并运行输入测试；监听自己的输入时，推荐使用声卡或调音台的硬件直通监听。
