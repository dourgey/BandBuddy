# 鼓、钢琴与现代键盘

## 内容与导航

系统学习沿用「体系卡片 → 八阶段路线 → 知识正文」。专项练习沿用「乐器卡片 → 模块总览 → 独立练习」，知识正文不嵌入工作台。知识和练习之间可以往返，相关专项在正文底部折叠展示。

依据用户提供的《鼓、钢琴与现代键盘完整自学框架》和《鼓、钢琴与现代键盘练习框架》整理。`ensemble-source.json` 保存 44 个模块、24 个阶段、243 项原文专项、16 个可选方向和 20 条先修关系。文档中的未解析引用占位符不进入产品内容；未复制参考教材曲谱。

新增 130 个知识节点：共通知识、三个乐器体系、阶段应用和方向选择。共享基础优先展示 C01—C08；旧弦乐器应用保留原 ID 和链接。自动伴奏电子琴位于现代键盘可选支线，复杂手法不锁定基础内容。

三个新乐器合计 365 个练习入口。243 项源任务全部保留；共通任务按三种乐器分别提供入口，另外增加阶段应用与方向项目。练习分为演奏、听觉、分析、设备、项目五类，任务无需外部音频输入即可打开和计时。

## 材料与执行

- 161 个固定谱例／变体，由 `ensemble-material.ts` 中的事件驱动谱面、合成参考音和高亮。鼓使用带鼓件图例的节奏网格，键盘使用大谱表及实际音高键盘图。
- 谱例覆盖基础拍点、手序、动态、鼓组律动、加花回拍、音阶、双手、和弦连接等。三个文档示例 D07-02、P06-01、K02-04 保留指定材料。
- 陌生旋律、节奏与和弦可刷新；听觉任务默认隐藏答案并播放参考音，停止后核对。
- 拍速绑定明确音符单位：4/4 为四分音符、6/8 为附点四分音符、7/8 示例为八分音符。支持预备拍、稀疏点击、静音小节与循环，静音小节不显示动态音符提示。
- K08 提供基础声源波形、ADSR、低通滤波、LFO 音高／音量／滤波调制的单参数听觉比较。
- 没有固定谱例的练习以原文执行要求、具体概念例子、准备、迁移任务和里程碑呈现。作品、合奏、设备和现场任务在实际乐器或设备上执行，软件提供任务计时与自评记录。
- 「完成／稳定／迁移」是用户自评。复盘文字与自评按练习 ID 存在本地 `bandbuddy.ensemble.practice.v1.*`；损坏记录回退为空。不采集音频、MIDI、视频，也不自动评分。

合成参考音用于核对节奏、音高与层次，不替代真实鼓组发声、踩镲闭合、钢琴触键、踏板或具体键盘音色。设备支线不意味着软件新增了硬件 MIDI 录制、自动伴奏引擎或插件宿主。

## 实现与验证

当前工作树原始提交为 `f484283`，为遵循当前软件的组织方式，先接入 `3080025` 已提交的练功房模块、主页面和兼容的 SelectMenu；没有复制主目录未提交的工作，也没有合并其他业务功能。

核心文件：

- `ensemble-source.json`：源框架、练习及关系。
- `ensemble-notes.ts`：原创知识解释、例子与易错点。
- `ensemble-curriculum.ts`：阶段归属、知识映射、任务分类和项目。
- `ensemble-material.ts`：独立于弦号／品位的乐器事件与谱例。
- `EnsemblePractice.tsx`、`EnsembleScore.tsx`、`EnsembleKeyboard.tsx`：练习、谱面及键盘展示。
- `ensemble-audio.ts`：使用音频时钟调度的参考播放、节拍、静音和取消处理。

测试覆盖源内容完整性、唯一 ID、双向引用、谱例边界、独立声部、三份示例、复合拍时间、静音小节、输出路由竞态和销毁后的停止。

验证使用现有依赖直接执行 TypeScript、Vitest、electron-vite。浏览器验证使用现有 Playwright 和本机 Chromium，地址为 `http://127.0.0.1:5193/?fixtures`，曲库为开发用模拟数据。桌面 1440×1000、窄屏 390×844。硬件演奏、实际监听听感及打包分发不在该验证范围。
