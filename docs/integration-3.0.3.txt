BandBuddy 3.0.3 教材 / MusicXML 与工具箱整合

对应 3.0.2 后续更新：
- 纳入完整外置教材：259 篇 JSON 正文，电吉他/原声吉他等乐器视图、章节导航、知识与练习往返、图示和谱例加载。
- 纳入 MusicXML 生成及 SVG 阅读器，用于教材、弦乐专项练习和合奏谱面；保留综合练习阶段及播放事件映射。
- 127 份作者谱例通过音符/声部/小节时值完整性检查；构建流程新增 verify:learning。
- 整体删除工具箱演奏工作台入口、页面和专用 instrument-workshop 模块；删除仅用于这些旧模块的测试，调音录音保护测试迁到现用调音器。
- 删除旧鼓机界面，仅保留 sample-drums 的采样鼓机，显示名统一为“鼓机”。共六个工具：节拍器、调音器、鼓机、和弦查询、五度圈、持续参考音。
- 删除工具卡片“点击打开”；工具 CSS 与 SVG 颜色采用软件主题变量，支持暖色/深色；保留乐器控件形状和音高/录音等状态语义。

验证：
123 个测试文件通过，677 项测试通过，1 项外部 NAM 模型测试跳过。
node/web TypeScript、生产构建、sandbox preload/worker 完整性、34 个 FLAC 鼓样本检查通过。
127 份 MusicXML：321 小节、1242 音符检查通过。教材测试覆盖所有索引正文、资源和乐器视图。
Edge/Playwright：六工具暖色与深色、采样鼓机编排/打击垫切换、教材正文、MusicXML 实际渲染与音符事件、390px 页面检查；Browser plugin not available。
最终包启动及哈希见 release-portable-3.0.3/build-manifest.json。Windows 包未签名，不代表已完成真实声卡/麦克风、干净 Windows 或 macOS 验收。

本报告取代 3.0.2 报告中的“教材/MusicXML 未纳入”说明。演奏工作台和旧鼓机属于本次明确要求删除的内容，不再作为缺漏恢复。
