# 外观与后续换肤接口

## 偏好与边界

`AppSettings.appearance` 的第一版格式：

```ts
{ schemaVersion: 1, theme: 'warm' | 'dark' | 'system',
  density: 'normal' | 'compact', effects: 'standard' | 'reduced' }
```

旧配置及无效字段分别恢复默认值：暖纸色、普通密度、标准效果。`appearance.get/set/onChanged` 只读写外观；组件使用它即时保存，不调用通用 `settings.update`。设置弹窗保存其他选项前读取最新外观，避免打开时的旧草稿撤销其他窗口的更改。

主窗口和歌词使用同一规范化函数；主题读取与广播有代次保护，迟到的启动响应和失败的保存不会覆盖更新后的主题。LAN 只收主题、密度和效果三个字段，并在设备自身解析系统模式。

## 样式组织

- `theme-tokens.css` 是换肤契约。基础变量包括字体、字号、圆角、间距和控件尺寸；语义变量包括页面、层级表面、文字、焦点、边框和状态；音乐变量包括分轨、波形、谱面、指板及琴键。
- `theme.css` 组织应用外壳与共享控件。既有功能 CSS 放入 `components` 层，所有入口明确 `theme, base, components, utilities` 的层序，防止懒加载改变最终视觉。
- 新组件用语义变量表达作用，不直接绑定暖色十六进制值。预设图片、黑胶唱片图案和具有物理含义的琴键仍可保留自身色彩。
- SVG／Canvas／第三方波形组件通过 `useResolvedTheme` 或 `bandbuddy:theme-changed` 重新读取 `themeColor`。只更新绘制属性，主题不加入音频加载、输出设备、录音或模型服务的依赖数组。
- 字体使用本地系统字体回退，图标从打包的 Lucide/SVG 加载。

## 交互组件

共享的 Select 保留表单值语义，自绘可见控件与菜单，支持方向键、Home/End、输入匹配、Escape、焦点返回、分组和禁用项。弹出层依附当前弹窗并按视口避让；支持时进入浏览器 top layer，避免被滚动容器和变换祖先裁切。

确认和输入弹窗通过异步队列串行展示；中文输入法组合期间 Enter 不提交。音频预览使用统一播放器，保留进度、音量和静音。系统文件选择及权限提示仍交给操作系统。

## 新皮肤扩展约束

增加内置皮肤时先补语义和音乐变量，再扩展版本化偏好与 IPC 校验及 LAN 白名单。对旧版本未知的皮肤提供暖色回退；不要让新字段触发通用环境初始化。

密度改变需要同步虚拟列表的行高与可视区测量。禁止仅修改 CSS 行高却保留旧的窗口化估算。减少效果仅关闭装饰动画、过渡和毛玻璃，不改变音乐时钟、预备拍或录音精度。

验收至少覆盖主窗口、桌面歌词、LAN、所有弹窗和菜单、谱面／键盘／指板／波形、错误／禁用／加载状态，以及播放和录音过程中切换主题。外观变化不应生成新的音频引擎实例。
