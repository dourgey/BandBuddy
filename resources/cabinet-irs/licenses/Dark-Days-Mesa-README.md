# Dark Days - Mesa 2x12 (Celestion Vintage 30) IRs

The complete mic-position grid of a Mesa 2x12 (Celestion Vintage 30,
closed back, cloth grille), captured with a Sennheiser MD421:

- Positions: cap / cone / edge, at 1 in, 2 in and on the grille,
  plus a 30-degree off-axis edge position.
- Three curated mixes: Tight (cap+edge close), Balanced, Deep.
- 48 kHz files in the root, 44.1 kHz in `44k1/`. 24-bit, ~460 ms.

Naming: `position_distance` - cap is brightest and most aggressive,
cone warmer, edge darkest; closer is drier and more in-your-face.
Start with `cap_1in` for the classic tight-metal sound.
